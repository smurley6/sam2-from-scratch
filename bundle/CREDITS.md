# Sample media credits

- `clips/blackswan`, `clips/bmx-trees`, `clips/libby`: first 48 frames of the DAVIS 2017
  validation sequences of the same names, 480p, resized to 640x360 and re-encoded as JPEG quality 80.
  DAVIS: Pont-Tuset et al., "The 2017 DAVIS Challenge on Video Object Segmentation",
  licensed CC BY-NC 4.0. Used here for a non-commercial personal demo.
- `images/truck.jpg`, `images/cars.jpg`, `images/groceries.jpg`: example images from the
  facebookresearch/sam2 repository notebooks (Apache-2.0), downscaled to 1280 px.
