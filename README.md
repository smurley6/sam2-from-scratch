# SAM 2 from scratch

A from-scratch PyTorch reimplementation of the inference architecture of
*SAM 2: Segment Anything in Images and Videos* (Ravi et al., 2024), verified numerically
against Meta's released SAM 2.1 weights, exported to ONNX, and running in the browser at
[stevenmurley.com/projects/sam2](https://stevenmurley.com/projects/sam2).

See `docs/PROGRAM.md` for scope, decisions, and status.
